# シート帳へ送る（Chrome拡張機能）

いあきゃら・ゆとシート・キャラクター保管所などで開いているシートを、キャラクターシート帳へ取り込める形でコピーします。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. ツールバーのパズルアイコンから「シート帳へ送る」をピン留めする

## 使い方

1. キャラクターシートのページを開く
2. 能力値も送りたいときは、先にサイトの「ココフォリア出力（駒をコピー）」ボタンを押す
3. 拡張機能のアイコンを押し、「コピーしてシート帳を開く」を押す
4. 開いたシート帳で ⌘V を押し、内容を確かめて「取り込む」を押す

元のシートのURLが同じキャラクターがシート帳にいれば、新しく作らずにそのキャラクターを更新します。

## いあきゃら

いあきゃらにログインした状態で、いあきゃらのどのページでも拡張機能のアイコンを押すと、次のボタンが出ます。

- **いあきゃらの全キャラ（N人）をシート帳へ送る**: マイページにある自分のキャラをまとめて送ります。シートを1枚ずつ開く必要はありません。
- シートを開いているときは、そのキャラ1人だけを送ることもできます。

読み取りには、いあきゃらがマイページを表示するときと同じ仕組み（ログイン中のセッション）を使います。ログイン情報はいあきゃらのページの中で使うだけで、拡張機能やシート帳には渡しません。

能力値の合計・HP・MP・DB・技能の合計値は、いあきゃらの元データから拡張機能が計算しています（6版・7版の標準ルール）。年齢による補正など、特殊な補正は反映されません。現在SANが0のまま保存されているシートは、ロストでなければ初期SANとして扱います。

## 仕組み

- ページ内に表示されているココフォリア駒データ（`{"kind":"character",…}`）か、クリップボードにある駒データを読み取ります。
- 見つからないときは、名前とURLだけを送ります。
- 任意のサイトで使えます。サイト名を表示する対象は `popup.js` の `SITES` で、vinsanet・キャラッシュのドメインはここに追加してください。
- シート帳のURLはポップアップの「設定」で変更できます。
