# シート帳へ送る（Chrome拡張機能）

いあきゃら・キャラッシュ・vinsanet・ゆとシート・キャラクター保管所・キャラクターシート倉庫などのシートを、Notionの「キャラクターシート帳」データベースへ追加します。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. ツールバーのパズルアイコンから「シート帳へ送る」をピン留めする

## Notionの設定

1. https://www.notion.so/profile/integrations で内部インテグレーションを作り、トークンをコピーする
2. Notionのキャラクターシート帳を開き、右上の「…」→「コネクト」で作ったインテグレーションを接続する
3. 拡張機能のアイコンを押し、「設定」にトークンを入力して保存する

トークンはこのChromeの中（`chrome.storage.local`）だけに保存します。

## 使い方

全キャラを読めるサイトでアイコンを押すと、新規と追加済みの人数と「新規 ○人をNotionに追加」ボタンが出ます。元のシートのURLで判定するので、追加済みのキャラ（Notionで変えたHP・SANなど）には触れません。

途中で画面を閉じると追加は止まりますが、もう一度押せば続きから追加します。

追加済みのキャラを元のシートの内容で更新する機能はありません。元のシートを変えたときは、Notionのページを直接直してください。

## いあきゃら

いあきゃらにログインした状態で、いあきゃらのどのページでも拡張機能のアイコンを押すと、次のボタンが出ます。

- **新規 N人をNotionに追加**: マイページにある自分のキャラのうち、新規だけを追加します。シートを1枚ずつ開く必要はありません。
- シートを開いているときは、そのキャラ1人だけを追加することもできます。

読み取りには、いあきゃらがマイページを表示するときと同じ仕組み（ログイン中のセッション）を使います。ログイン情報はいあきゃらのページの中で使うだけで、拡張機能やNotionには渡しません。

能力値の合計・HP・MP・DB・技能の合計値は、いあきゃらの元データから拡張機能が計算しています（6版・7版の標準ルール）。年齢による補正など、特殊な補正は反映されません。現在SANが0のまま保存されているシートは、ロストでなければ初期SANとして扱います。

## キャラッシュ

キャラッシュ（charash.jp）にログインした状態で、キャラッシュのどのページでもアイコンを押すと「新規 N人をNotionに追加」が出ます。シートを開いていれば、そのキャラ1人だけも追加できます。

- エモクロアTRPG・ガイアケアTRPG：能力値8種、HP・MP、共鳴、技能の判定値（関連する能力値＋技能レベル）、チャットパレット（`2DM<=7 〈聞き耳〉` の形）を追加します。
- CoC6版・7版・10_st・オリジナル：今は名前・URL・プロフィール・メモだけを追加します。
- ネタバレメモは追加しません。

読み取りには、キャラッシュの一覧ページと、シートを表示するときと同じ仕組み（ログイン中のセッション）を使います。

## vinsanet（Kutulu）

vinsanet のマイページ（https://vinsanet.com/mypage）を開いてアイコンを押すと「新規 N人をNotionに追加」が出ます。シートの閲覧ページでは、そのキャラ1人だけも追加できます。

- 能力値: 基本技能（敏捷・筋力・隠密・射撃・白兵・名声・弁舌・家格・信用）と負傷
- 技能: 1以上の専門技能（機械工学・言語学など）
- タグ: vinsanet のタグ、基本ルール以外のルール名（「B級ホラーパーティ」など）、ロスト
- メモ: 肩書き・年齢・職業・出身・階級・家庭と、備考
- チャットパレットは作りません（Kutulu の判定コマンドをまだ確認していないため）

vinsanet が公開している API（`/api/v1/characters/{id}`）でシートを読み取ります。マイページのキャラ一覧はリンクではなくボタンなので、各「閲覧」ボタンの行き先だけを読み取ってIDを集めます（ページは移動しません）。

## ゆとシート

ゆとシート（yutorize.work / yutorize.2-d.jp）のキャラクターシートを開いてアイコンを押すと、そのキャラ1人を追加できます。どのシステムのシートでも使えます。

- 名前・よみ・コードネーム（ないときはクラスやワークス）・プロフィール・PL名・メモ
- ステータス: シートの「ユニット（コマ）」の値（HP・侵蝕・耐久値など）
- タグ: シートのタグと、セッション履歴のシナリオ名
- チャットパレット: ゆとシートが出力するBCDice用のもの
- 能力値と技能はダブルクロス3rdだけ読み取ります（肉体・感覚・精神・社会と、成長させた技能）

ゆとシートのJSON出力（`?id=…&mode=json`）とチャットパレット出力（`&mode=palette&tool=bcdice`）で読み取ります。一覧からの一括追加はまだできません。

## キャラクター保管所

キャラクター保管所（charasheet.vampire-blood.net）のシートを開いてアイコンを押すと、そのキャラ1人を追加できます。

- クトゥルフ神話TRPG 6版: 能力値・HP・MP・SAN・成長させた技能（目星・聞き耳・図書館・回避は常に）・チャットパレット
- そのほかのシステム: 名前・プロフィール・メモ・タグだけ

キャラクター保管所のJSON出力（`/<シートのID>.js`）で読み取ります。一覧からの一括追加はまだできません。

## 仕組み

- ページ内に表示されているココフォリア駒データ（`{"kind":"character",…}`）か、クリップボードにある駒データを読み取ります。
- 見つからないときは、名前とURLだけを追加します。
- 任意のサイトで使えます。サイト名を表示する対象は `popup.js` の `SITES` で、vinsanet・キャラッシュのドメインはここに追加してください。
- シート帳のURLはポップアップの「設定」で変更できます。

## キャラクターシート倉庫

キャラクターシート倉庫（character-sheets.appspot.com）のシートを開いてアイコンを押すと、そのキャラ1人を追加できます。どのシステムでも名前・ふりがな・プロフィール・メモは入ります。トーキョーN◎VA THE AXLERATION は能力値・制御値と技能・特技のレベルも入ります。

- 概要: 二つ名とスタイル
- システム: シートのページ名

キャラクターシート倉庫のJSON出力（`/<システム>/display?ajax=1&key=…`）で読み取ります。一覧からの一括追加はまだできません。
