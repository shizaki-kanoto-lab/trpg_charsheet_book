    Notionから更新する

    この画面から公開データを作り直すには、GitHub のトークンが要ります。最初の1回だけ設定してください。

    1. GitHub のトークン作成画面 ↗を開きます（ でログイン）。
    2. Repository access で「Only select repositories」→ を選びます。
    3. Permissions の Repositories で「Actions」を「Read and write」にして作成します。
    4. 表示されたトークン（github_pat_…）を下に貼り付けます。

    トークンはこのブラウザの中だけに保存され、GitHub 以外には送りません。

    トークンを作らずに更新するときは GitHub の Actions 画面 ↗ で「Run workflow」を押してください。
